# Cluster — ต้นแบบส่วนที่ผูกกับคลินิก

ต้นแบบที่กดได้ของ Cluster รุ่น 1 สำหรับนำเสนอ ไม่มีเซิร์ฟเวอร์และไม่มีข้อมูลจริง ทุกอย่างอยู่ในเบราว์เซอร์ของเครื่องที่เปิด

## วิธีเปิด

```bash
npm install
```

```bash
npm run dev
```

แล้วเปิด http://localhost:5173

## หน้าที่มี

| ที่อยู่ | คืออะไร |
|---|---|
| `/` | เวทีสาธิต: แอปฝั่งผู้ใช้ คอนโซลคลินิก และที่เก็บข้อมูลของแต่ละฝ่าย เรียงข้างกันและอัปเดตพร้อมกัน |
| `/app` | แอปฝั่งผู้ใช้ (มือถือ): แผนที่ รายการจุดบริการ ส่งสัญญาณ บอกต่อ ดูแลตัวเอง ช่วยเหลือ |
| `/r#…` | หน้าของผู้รับลิงก์ เนื้อหามาจากส่วนท้ายของลิงก์เท่านั้น |
| `/clinic` | คอนโซลคลินิก: ออกรหัส บันทึกผล ยอดรวมรายสัปดาห์ รหัส fast-track ช่วยแจ้งผู้สัมผัส |
| `/operator` | หลังบ้านผู้เผยแพร่: ไฟล์ประจำสัปดาห์ เรื่องร้องเรียน ข้อมูลที่เก็บ |
| `/data` | ข้อมูลอยู่ที่ไหน: สิ่งที่แต่ละฝ่ายถืออยู่ ลำดับเหตุการณ์ และตารางใครรู้อะไร |
| `/design` | สี ตัวอักษร และชิ้นส่วน UI |

ลิงก์ลัดสำหรับนำเสนอ: เติม `?seed=pilot` หรือ `?seed=threshold` เพื่อเริ่มจากข้อมูลสาธิต และ `?phase=2` เพื่อดูตัวอย่างสัญญาณระดับโซน เช่น `/?seed=threshold`

## ลำดับการนำเสนอ 8 ขั้น

เปิดหน้า `/` แล้วกด "ถัดไป" ทีละขั้น เวทีจะตีกรอบช่องที่ต้องทำในขั้นนั้นและเปิดหน้าที่ต้องใช้ให้

1. คอนโซลคลินิก → ออกรหัส → กดออกรหัสให้ผู้มาตรวจ
2. คอนโซลคลินิก → บันทึกผล → เลือกผลบวกให้รหัสนั้น
3. แอป → ส่งสัญญาณ → เลือกกลุ่มโรคเดียวกัน → มีรหัสจากคลินิก → ใส่รหัส
4. ติ๊ก "ให้คลินิกนับรวมเป็นสัญญาณของกรุงเทพฯ" → กด "ส่งให้คลินิกนับรวม" แล้วดูหน้าสรุป
5. กด "บอกต่อคนที่อาจเกี่ยวข้อง" → ตอบคำถามความปลอดภัย → ส่งลิงก์เอง → เลือกช่วงเวลา → สร้างลิงก์
6. กด "เปิดหน้าของผู้รับ" → ดูรายละเอียด
7. คอนโซลคลินิก → ยอดรวมรายสัปดาห์ → ส่งยอดรวม
8. คอลัมน์ข้อมูล → เผยแพร่ไฟล์สัปดาห์นี้ → ดูแผนที่ในช่องแอป

รายงานเดียวจะยังไม่ถึงเกณฑ์ 10 แผนที่จึงแสดง "ต่ำกว่าเกณฑ์" ซึ่งเป็นพฤติกรรมที่ตั้งใจ

ถ้าต้องการแสดงสภาพเมื่อมีรายงานพอ ให้เลือก "ถึงเกณฑ์ 10" ที่ "ข้อมูลเริ่มต้น" **ก่อน** เริ่มขั้นที่ 1 ปุ่มนี้ล้างข้อมูลสาธิต ใส่ยอดรวมจากคลินิกอื่นอีกสองแห่ง แล้วเผยแพร่ให้เอง รายงานที่ทำในขั้นที่ 1 ถึง 8 จะบวกเพิ่มเข้าไป ไม่ทับของเดิม

ปุ่ม "ข้ามไปสัปดาห์ถัดไป" ในคอลัมน์ข้อมูลใช้แสดงว่าสัญญาณเปลี่ยนอายุและหมดอายุเอง: จาก "ถึงเกณฑ์ 10" กด 1 ครั้งจะเป็น "ผสม" กดครบ 4 ครั้งจะเหลือ "ต่ำกว่าเกณฑ์" และครบ 12 ครั้งจะเป็น "ยังไม่มีข้อมูล" พร้อมกับที่ยอดรวมบนเซิร์ฟเวอร์ถูกลบ

ระหว่างนำเสนอ ถ้าช่องแอปค้างอยู่ที่หน้าว่าง (หลังกด "ออกเร็ว") หรือหน้าของผู้รับ ให้กด "กลับไปแผนที่" เหนือช่องนั้น

## สิ่งที่จำลอง

- ที่เก็บข้อมูล 4 ฝ่าย (เครื่องผู้ใช้ คลินิก เซิร์ฟเวอร์ ไฟล์ที่เผยแพร่) คือคีย์แยกกันใน `localStorage` ของเบราว์เซอร์เดียว
- จุดบริการทั้งหมดเป็นชื่อสมมติ และตัวเลขทางการเป็นตัวเลขสมมติ
- แผนที่เป็นแผนผังกรุงเทพฯ แบบย่อที่วาดเอง ไม่ตรงมาตราส่วน
- รหัส fast-track รายสัปดาห์คำนวณด้วยแฮชธรรมดา ไม่ใช่ความลับ
- การตรวจรหัสคลินิกในแอปอ่านที่เก็บของคลินิกโดยตรง แทนบริการตรวจรหัสจริง แอปได้คำตอบแค่ว่ารหัสมีอยู่จริงไหม ไม่ได้ผลตรวจ
- ข้อความทางคลินิกเป็นร่าง ยังไม่มีแพทย์ลงนาม

## โลโก้

โลโก้ที่หัวแอปคือภาพ `src/design/logo/mark.png` และ `src/design/logo/word.png` ซึ่งตัดจากไฟล์โลโก้ของเจ้าของโปรเจกต์ด้วย `scripts/logo/cut.py` ไฟล์ต้นทางไม่ได้อยู่ใน repo นี้ และยังไม่มีไฟล์เวกเตอร์

```bash
python3 scripts/logo/cut.py <ไฟล์โลโก้ต้นทาง.png> src/design/logo
```

## สิ่งที่รุ่นจริงต้องมี

ดูแผนผลิตภัณฑ์ของ Cluster (เอกสารภายใน ไม่ได้อยู่ใน repo นี้) หัวข้อกฎหมาย และหัวข้อเฟสกับประตู โดยเฉพาะ

- คำตอบของหน่วยงานเรื่องการเก็บข้อมูลจราจร
- ทะเบียนเนื้อหาทางคลินิกที่แพทย์ลงนาม
- รายชื่อจุดบริการจริงที่ยืนยันแล้ว
- กติกาการเผยแพร่ที่ต้นแบบยังไม่ทำ: การใส่ noise และการไม่เผยแพร่เมื่อความต่างจากรอบก่อนมาจากรายงานน้อยกว่า 10 รายการ
