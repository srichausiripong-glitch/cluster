# pharmacies.json

pharmacies.json is derived from OpenStreetMap data, © OpenStreetMap contributors, and is available under the Open Database License (ODbL) 1.0: https://opendatacommons.org/licenses/odbl/

It is made by `npm run care:fetch` (scripts/care/fetch.ts) from the pharmacies (`amenity=pharmacy`) inside Bangkok. Each entry's `source` links to the OpenStreetMap object it was copied from, and `fetched` gives the day it was copied.
